# 无线连接设备

## 模拟器连接

`10.0.2.15` 常是模拟器内部 NAT（网络地址转换）网络的地址。电脑应使用模拟器公布的本机 ADB 映射地址（形如 `127.0.0.1:端口`），不要把内部地址直接作为电脑的连接目标，也不要假定所有模拟器都使用端口 5555。多开实例的端口可能不同。

## 手机无线调试

- Android 11 及以上：在“开发者选项 → 无线调试 → 使用配对码配对设备”取得配对地址和 6 位配对码，先执行“配对”。
- 配对成功后返回无线调试主页，将主页的 IP 地址和连接端口填入“连接地址”，再点击“连接”。**配对端口与连接端口不同**，且连接端口不一定是 5555。
- 传统 `adb tcpip` 模式只在设备已开启对应服务时可连接；工具箱不会自动修改设备调试模式。省略连接端口时按 5555 处理，配对地址则必须写明端口。
- IPv6 请写为 `[地址]:端口`。设备与电脑需要网络可达；超时或连接被拒绝时先检查地址、端口、无线调试状态和网络隔离。

## 程序处理规则

- 无线操作调用同一路径的官方 ADB CLI，配对不再使用手写 host 协议，也不再对配对端口自动执行连接。
- `WirelessAdb` 同时验证退出码和明确的成功文本，失败回复即使退出码为 0 也不得当成成功。
- 无线连接确认使用 `ContentDialogButtonClickEventArgs.GetDeferral()` 等待异步结果。请求期间禁用重复操作，超时或失败保留窗口及错误提示，成功后刷新统一设备会话。
- 只保存成功的连接地址，不保存配对码；不会自动把用户输入的地址替换成其他设备地址。

验证步骤见 `Tests/README.md`。
